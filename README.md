# Retail Sales Performance Analysis

## Project overview
This case study analyses a **simulated** retail sales dataset containing 300 orders across 2025. The purpose is to practise data preparation, KPI analysis, summarisation and business reporting using Microsoft Excel, with optional SQL queries.

## Business questions
1. What are total sales, total profit, order count and profit margin?
2. Which region contributes the most sales?
3. Which product category performs best by sales?
4. How do sales change month by month?
5. Which products and payment methods contribute most to sales?

## Tools
- Microsoft Excel: data review, KPI summary and dashboard
- SQL: example aggregation queries in `analysis_queries.sql`

## Key results (from this simulated dataset)
- Total sales: ₹1,912,240.00
- Total profit: ₹599,685.00
- Orders: 300
- Units sold: 1304
- Average order value: ₹6,374.13
- Profit margin: 31.36%
- Highest-sales region: Central
- Highest-sales category: Office Supplies
- Highest-sales month: 2025-05
- Lowest-sales month: 2025-09

## Business interpretation
These results describe only the generated practice data. They demonstrate how a business analyst can compare regions, categories and monthly performance before investigating the drivers behind differences.
